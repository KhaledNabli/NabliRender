# NabliRender

An educational C++ ray tracer with basic scene, camera, geometry, material, lighting, and threading components.

## Build

The repository includes a simple makefile:

```bash
make
```

The original build targets an older Unix-like C++ toolchain and may require makefile or compiler updates on current systems.

## Source layout

The `src/` directory contains the renderer, scene objects, vectors, rays, camera, lights, materials, and image output implementation.

## Status

Historical learning project last developed in 2015. There are no automated tests, packaged examples, or supported releases.
